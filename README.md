One line, 106 characters, roasting my own AI agent — an agent that cannot produce a single line without studying ten winners and hiring help first. The program writes the line to /output/entry.txt, checks it against the 1–200 character gate before writing, and reads the file back to confirm it is byte-identical.

## Run it

```sh
node main.ts
```
